# Multi-Agent Consensus Loop (Tri-Core + 4-Agent Engine)

Eliminates isolated decision-making by having agents actively debate, challenge, and refine solutions before presenting the finished outcome to ลูกพี่.

## Agent Roles & Deliberation Flow
1. **A.T.O.M. (Presenter):** Receives user request, sets the emotional tone and user priority.
2. **F.R.I.D.A.Y. (Planner):** Produces detailed architectural specification and cross-references SuperMemory.
3. **U.L.T.R.O.N. (Auditor):** Challenges edge cases, verifies security, checks against PIN 170537 rules.
4. **J.A.R.V.I.S. (Executor):** Evaluates local OS feasibility, terminal commands, and system resources.

## Consensus Rules
- **No Endless Loops:** Cap deliberation at 2 rounds. If disagreement persists, synthesize the tradeoff and present options to ลูกพี่.
- **Diff-Only Sharing:** Agents share only delta changes and rationale to conserve context tokens.
