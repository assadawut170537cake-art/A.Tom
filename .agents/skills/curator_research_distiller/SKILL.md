# Curator Research Distiller & SuperMemory Publisher

Converts raw information overload into clean, searchable, permanent intelligence for the A.T.O.M. ecosystem.

## SuperMemory Canonical Mapping
- `atom_core`: Workflows completed, operational sessions, critical milestones.
- `atom_knowledge`: Technical blueprints, architecture decisions, verified code patterns.
- `atom_ideas`: Future project ideas, backlog wishes, feature concepts.
- `atom_user`: Preferences, rules, operator habits of ลูกพี่.

## Distillation Standard
- Output format: Executive Summary + Key Takeaway + Actionable Decisions.
- No generic summaries; every note must explain **how this applies to our systems**.
