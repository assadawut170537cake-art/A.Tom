# CONCEPT — แกนหลักของ A.T.O.M. (Boss ยืนยัน 2026-10-20)

> ไฟล์นี้ = เข็มทิศ · งานใหม่ทุกชิ้นต้องตอบได้ว่าช่วยข้อไหนด้านล่าง · ไม่ช่วยข้อไหนเลย = ของเสริม (ทำทีหลัง)
> ตัวอย่างที่บอสใช้เป็นแบบ: คลิปแอปคุยเสียงสด (Orb จุดอนุภาค + บับเบิลคำพูดสองฝั่ง) · ถ้าไม่ได้ ให้ลื่นอย่างน้อยเท่า ChatGPT Voice

## แกนหลัก (ต้องทำได้ก่อนอย่างอื่น)

### 1. คุยลื่นเหมือนคน
- พูดแล้วได้ยินคำตอบเร็ว · พูดแทรกได้ · เสียงธรรมชาติ (เสียงหลัก = Gemini)
- ขึ้นคำพูดสด ๆ ทั้งสองฝั่งเป็นบับเบิล · สลับไปพิมพ์ได้
- หน้าจอเรียบ: ชื่อ persona ด้านบน · Orb กลางจอ · ✕ / 🎙️ / ➕ / "พิมพ์" ด้านล่าง
- หน้าตา/persona ของเราตอนนี้ใช้ต่อได้ — ที่ต้องแก้คือ **ลักษณะการคุย** (ตอนนี้ช้าและเป็นทอด ๆ)

### 2. ส่งงานต่อให้แอปอื่น
- คุยแล้วสั่งงาน → ผู้ช่วยส่งต่อให้แอป/บริการที่ทำได้ (ใช้ความสามารถของแอปอื่นแทนการสร้างเอง)

### 3. หาและสร้างความสามารถเอง
- ค้นเองว่างานนี้ต้องใช้ ทักษะ / ปลั๊กอิน / MCP ตัวไหน — ค้นจากภายนอกได้ ไม่ต้องรอบอสติดตั้งไว้ก่อน
- หาไม่เจอ → เขียนทักษะใหม่เอง
- ของที่มีแล้ว: คลัง MCP ทางการ (Marketplace) · ทักษะที่ AI เรียนรู้เอง (`learnFrom`)

### 4. ซ่อมตัวเอง + เรียนรู้จากการแก้
1. เจอข้อผิดพลาด → **snapshot ก่อน** แล้วแก้
2. แก้ผ่าน → **จดวิธีลงบันทึกการเรียนรู้** + ลบ snapshot · ครั้งหน้าเจออีก → ลองหาวิธีที่เร็วกว่าเดิม
3. แก้ไม่ผ่าน → จดว่าวิธีนี้ไม่ได้ผล → **ย้อนกลับไป snapshot** → ลองวิธีถัดไป (วนจนได้)
4. snapshot / backup **เก็บซ้อนไม่เกิน 3–5 ชุด** (เก่าสุดลบทิ้ง) ไม่ให้กองพะเนิน

## กรอบความปลอดภัย (ใช้กับข้อ 3–4)
- **ทำเองได้ทันที:** การตั้งค่า ข้อมูล การเลือกผู้ให้บริการ — มี snapshot ย้อนกลับได้
- **ต้องรอบอสอนุมัติก่อนใช้จริง:** แก้โค้ดของแอป · เพิ่ม MCP ใหม่ (เพิ่มแล้วปิดไว้ก่อน) · ทักษะที่ AI เขียนเอง (เข้า prompt)
- คำสั่งเสี่ยง (ซื้อ/โอน/ลบ/ส่งข้อความ) ถามยืนยันก่อนเสมอ (เดิม)

## ของเสริม (ทำหลังแกนหลัก)
Mark 55 / PC · ห้องแชทข้ามเครื่อง · Supermemory · อัลตรอน sandbox · โหมดเฝ้า · ควบคุมมือถือระดับ B · Marketplace UI · ผู้ให้บริการสำรอง (Dahl / xAI / เพิ่มเอง)

## ลำดับงานต่อจากนี้
1. **คุยลื่น** (ข้อ 1) — โหมดเสียงสดแบบ realtime · ทำทีละชิ้น (สตรีมเสียง native → ต่อ API → UI บับเบิล/Orb)
2. **ส่งงานต่อ** (ข้อ 2) — ให้โหมดเสียงสดเรียก tool/agent ที่มีอยู่ได้
3. **หาความสามารถเอง** (ข้อ 3) — tool ค้นคลัง MCP / ทักษะ + เขียนทักษะ (รออนุมัติ)
4. **ซ่อมตัวเอง** (ข้อ 4) — snapshot ≤ 5 ชุด + บันทึกการเรียนรู้ · เริ่มจากการตั้งค่า/ข้อมูล
5. ย้ายของเสริมออกจากแกนตาม `docs/CORE_AUDIT.md`

## แนวคิดเพิ่ม (Boss 2026-10-20 — ของเสริม ทำหลังเสียงแบบ A)
- **Supermemory เป็นช่องสื่อสารกลาง:** แทนต่อ API ตรงระหว่างเครื่อง → อัปของลงโฟลเดอร์ Supermemory แล้วแต่ละ agent (จาร์วิส/ไฟรเดย์) poll อ่านเอง เจอคำสั่งของตัวเอง → ทำ → เขียนผลกลับขึ้น Supermemory ให้ฝั่งที่เกี่ยวตื่นมาอ่าน · ข้อจำกัด: Supermemory ไม่ push → ต้อง poll (ทุก 15–30s) · คำสั่งที่สั่งงานจริงต้องผ่านด่าน "ยืนยัน" · ทับกับ Mark 55 Bus (อนาคตอาจยุบมาช่องเดียว)
- **Daily Autonomous Researcher:** cron เช้า → ค้นสถาปัตยกรรม AI ใหม่ → เขียน "ข้อเสนอ" ต่อท้าย `docs/ROADMAP.md` (สถานะ รออนุมัติ) → บอสเคาะเอา/ตัด · researcher เสนอได้แต่แก้โค้ด/นำเข้าเองไม่ได้ (กรอบความปลอดภัยข้อ 3–4) · เวอร์ชันเบา = scheduled task ของ session (รอบอสสั่งตั้ง)
